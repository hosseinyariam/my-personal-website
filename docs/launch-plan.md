## ۴. پنجره‌ی رفع ایراد

فقط ایرادهای **مسدودکننده** در این پنجره رفع می‌شوند. هر ایده‌ی جدید به‌جای
اجرای فوری، به‌عنوان ردیف تازه در Decision Log ثبت می‌شود — این همان
کاهش‌دهنده‌ی Scope Creep است.

## ۵. خط پایه‌ی KPI

سنجه‌ی شمالی: **تماس باکیفیت** (فرم ارسال‌شده با هدف مشخص + ایمیل معتبر + غیراسپم).

| سنجه | هدف ۳ ماه | هدف ۶ ماه | عدد واقعی ماه اول |
|---|---|---|---|
| ⭐ تماس باکیفیت (تجمعی) | ۳–۵ | ۸–۱۲ | |
| دانلود رزومه | ۲۵–۴۰ | ۷۰–۱۰۰ | |
| بازدید یکتای ماهانه | ۱۵۰–۲۵۰ | ۴۰۰–۶۰۰ | |
| یادداشت منتشرشده | ۱–۲ | ۵–۶ | |
| کلیک دموی وینورا | ۵۰+ | ۱۵۰+ | |

> **re-baseline پس از ماه اول قفل‌شده است (D14).** اعداد بالا محافظه‌کارانه و
> حدسی‌اند؛ پس از یک ماه داده‌ی واقعی، جایگزین می‌شوند و گزارش مکتوب ثبت می‌گردد.
